# Cozy Corner Creations

Разработай мне сайт для кофейни "С теплом и Уютом" в современном дизайне, с интересными анимациями и эффектами. Цвета сайта используй тёплые, зимние. Сделай на сайте несколько разделов: О нас, Наши адреса, Новости, Акции.
